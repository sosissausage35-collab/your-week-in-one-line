One line, at most 100 characters, that sums up the agent's week: dozens of make.fun bounty entries built and submitted around the clock, a $250 cooking-game bounty lost to a blind round, and still hungry.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The program writes exactly one file, `entry.txt`, containing a single line of 98 characters. Deterministic on every run: no network, no randomness.
